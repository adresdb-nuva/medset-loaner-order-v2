# MedSet Loaner Order App

Dit is de broncode voor de MedSet Loaner Order applicatie.

## Lokaal Installeren en Starten

Volg deze stappen om de applicatie op je eigen computer te draaien:

1.  **Vereisten**: Zorg dat je [Node.js](https://nodejs.org/) geïnstalleerd hebt.
2.  **Downloaden**: Pak het gedownloade ZIP-bestand uit in een map.
3.  **Terminal**: Open een terminal (of command prompt) in deze map.
4.  **Installeren**: Typ het volgende commando en druk op Enter:
    ```bash
    npm install
    ```
5.  **Starten**: Typ daarna:
    ```bash
    npm run dev
    ```
6.  **Openen**: Ga in je browser naar de link die verschijnt (meestal `http://localhost:5173`).
